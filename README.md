# anayu15.github.io

La página personal de Ana Yusta en GitHub Pages: la página principal y la política de privacidad de sus herramientas
personales de solo lectura («lectores del Mac de Ana»), que Google exige para publicar la aplicación con la que esas
herramientas leen su Drive, su calendario y sus contactos. Dos ficheros HTML estáticos, sin maquinaria.
